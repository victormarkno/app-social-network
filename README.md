# Social Network App 👥

Aplicación de red social simple construida con **JavaScript puro**. Permite publicar mensajes y ver un feed de publicaciones.

**Live Demo:** [https://app-social-network-javascript.netlify.app/](https://app-social-network-javascript.netlify.app/)

## Características

- Publicar mensajes
- Feed de publicaciones en tiempo real (lado cliente)
- Interfaz simple e intuitiva
- Manejo de DOM y eventos

## Tecnologías

- JavaScript (Vanilla)
- HTML5
- CSS3
- Netlify (deploy)

## Cómo ejecutarlo localmente

1. Clona el repositorio:
```bash
git clone https://github.com/victormarkno/app-social-network.git
cd app-social-network
```

2. Abre `index.html` en tu navegador o usa un servidor local:
```bash
npx serve .
```
